# aetheris v2.1 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the v2.0.0 known gaps and the final whole-branch review's Important/Minor findings: pipe DACL least-privilege + privileged SaveConfig, overlay hotkey activation, overlay DPI + close affordance, non-blocking UI IPC, save/reload GameBoost re-entry, network-QoS crash reconciliation, and QoS PID-reuse protection.

**Architecture:** Continues the aetheris workspace (core/service/cli/ui/overlay). No new crates, no new external deps (windows/ntapi features only). Every change is either a core behavior fix (tested in `aetheris-core`) or a UI/overlay polish item (manual).

**Tech Stack:** Rust, windows 0.62.2, ntapi. Target Windows 10 1809+ / Win11.

## Global Constraints

- **No async runtime** anywhere.
- **Security:** the pipe DACL change (Task 1) must keep SYSTEM full access and interactive users read+write but NOT `WRITE_DAC`/`WRITE_OWNER`; `SaveConfig` must be gated to elevated callers via pipe impersonation + token check. Never weaken the protected-process list or per-process action gating.
- **Zero-overhead preserved:** hot path (policy event path) untouched by all tasks; everything runs on game-entry/exit or IPC.
- **Reversibility:** network QoS marker/reconcile (Task 6) must never double-revert or touch values the service itself didn't set.
- Dependencies locked; cargo-deny green. Every task ends green + committed.

`ipc.rs`: change the DACL constant; add `is_client_elevated`:

```rust
pub fn is_client_elevated(pipe: HANDLE) -> Result<bool, String> {
    unsafe {
        windows::Win32::System::Pipes::ImpersonateNamedPipeClient(pipe)
            .map_err(|e| format!("ImpersonateNamedPipeClient: {e}"))?;
    }
    // Thread token after impersonation is the client's.
    let mut token: HANDLE = HANDLE(0);
    let r = unsafe {
        windows::Win32::System::Threading::OpenProcessToken(
            windows::Win32::System::Threading::GetCurrentProcess(),
            windows::Win32::Security::TOKEN_QUERY,
            &mut token,
        )
    };
    // Always revert, regardless of the token read outcome.
    let _ = unsafe { windows::Win32::System::Threading::RevertToSelf() };
    r.map_err(|e| format!("OpenProcessToken (client token): {e}"))?;

    let mut elev = windows::Win32::Security::TOKEN_ELEVATION::default();
    let mut sz = 0u32;
    let r = unsafe {
        windows::Win32::Security::GetTokenInformation(
            token,
            windows::Win32::Security::TokenElevation,
            Some((&mut elev as *mut _).cast()),
            std::mem::size_of::<windows::Win32::Security::TOKEN_ELEVATION>() as u32,
            &mut sz,
        )
    };
    let _ = unsafe { windows::Win32::Foundation::CloseHandle(token) };
    r.map_err(|e| format!("GetTokenInformation: {e}"))?;
    Ok(elev.TokenIsElevated != 0)
}
```

> **Compile-fix note:** `ImpersonateNamedPipeClient` may be under `Win32::System::Pipes` or `Win32::System::Threading` in 0.62.2 — verify against the vendored crate. `TOKEN_ELEVATION`/`TokenElevation`/`GetTokenInformation` are under `Win32::Security`. `RevertToSelf` under `Win32::System::Threading`. If `GetTokenInformation`'s signature differs, adapt.

```rust
fn launch_overlay() {
    let exe = std::env::current_exe().ok();
    let dir = exe.and_then(|p| p.parent().map(|d| d.to_path_buf()));
    let overlay = dir.map(|d| d.join("aetheris-overlay.exe"));
    match overlay {
        Some(p) if p.exists() => {
            let w: Vec<u16> = p.to_string_lossy().encode_utf16().chain(std::iter::once(0)).collect();
            let mut si = std::mem::zeroed::<windows::Win32::System::Threading::STARTUPINFOW>();
            si.cb = std::mem::size_of::<windows::Win32::System::Threading::STARTUPINFOW>() as u32;
            let mut pi = std::mem::zeroed::<windows::Win32::System::Threading::PROCESS_INFORMATION>();
            let ok = unsafe { windows::Win32::System::Threading::CreateProcessW(
                Some(windows::core::PCWSTR(w.as_ptr())), None, None, None, false,
                windows::Win32::System::Threading::CREATE_NO_WINDOW, None,
                None, &si, &mut pi) };
            match ok { Ok(()) => { let _ = unsafe { windows::Win32::Foundation::CloseHandle(pi.hProcess) }; let _ = unsafe { windows::Win32::Foundation::CloseHandle(pi.hThread) }; }
                       Err(e) => crate::log::warn(format!("overlay launch failed: {e}")) }
        }
        _ => crate::log::warn("aetheris-overlay.exe not found next to the service"),
    }
}
```

### Task 4: Non-blocking UI IPC

**Files:**
- Modify: `crates/aetheris-ui/src/main.rs`
- Test: manual (dialog stays responsive during a service-down call)

**Interfaces:**
- Consumes: `client_call`, the existing `UiState`.
- Produces: all pipe calls (GetState, GetConfig, SaveConfig, ReloadConfig) run on a worker thread; results are `PostMessageW`d back to the dialog as a custom `WM_APP+1` message carrying a boxed `Response` (or an `Err(String)`); the wndproc applies the result to `UiState` under the existing reentrancy-safe guards. The dialog never blocks on IPC.

**Implementation approach:**
- Define `const WM_IPC_RESULT: u32 = WM_APP + 1;` and a message-lparam carrying a `*mut Box<Result<Response, String>>` (the worker allocates it; the wndproc takes ownership and frees it — match the existing `catch_unwind`/state-ownership discipline).
- Each button handler spawns a thread that runs `client_call` then `PostMessageW(hwnd, WM_IPC_RESULT, (call_id), lparam_box)`. The wndproc, on WM_IPC_RESULT, dispatches by call_id to the right state-update function (refresh status / apply config / show save result / reload).
- The service-down path now fails fast in the worker (no UI freeze). Keep the save-blocked-until-loaded guard.

In `set_config`, after swapping cfg/matcher/protected, call `self.reenter_if_game_running()`:

```rust
pub fn set_config(&mut self, cfg: Config) {
    self.exit_game_mode();
    self.cfg = cfg;
    self.matcher = PatternMatcher::new(self.cfg.game.processes.clone());
    self.protected = self.cfg.protected_set();
    self.rebuild_matchers();
    self.reenter_if_game_running();
}

pub fn reenter_if_game_running(&mut self) {
    if self.mode == Mode::GameBoost { return; }
    let table: Vec<(u32, String)> = self.table.iter()
        .filter(|(_, name, _)| self.is_game(name))
        .map(|(pid, name, _)| (pid, name.to_string()))
        .collect();
    if let Some((pid, name)) = table.into_iter().next() {
        self.enter_game_mode(pid, &name);
    }
}
```
