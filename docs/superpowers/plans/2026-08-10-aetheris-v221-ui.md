# aetheris v2.2.1 Simplified Bilingual UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the technical 3-list editor UI with a simplified bilingual (zh/en, default = system language) checklist UI: games + background-apps checklists, four global optimization toggles, a big status area, an add-by-name + running-process picker, and a collapsed advanced editor.

**Architecture:** The i18n foundation (`Lang`, system-language detection, bilingual config template, `ui.toml`) lands in `aetheris-core` (testable). `mode_ui.rs` is rewritten around a string table + a language-aware re-render; the existing per-row editor is preserved behind an "高级/Advanced" expander. Everything else (service, IPC, tray, single exe) is untouched except tray-menu strings.

**Tech Stack:** Rust, windows 0.62.2 (`Win32::Globalization::GetUserDefaultUILanguage`, `Win32::System::ProcessStatus::EnumProcesses` / `QueryFullProcessImageNameW`, existing `Win32_UI_*`), serde/toml for `ui.toml`.

## Global Constraints

- **No async runtime.** UI stays single-threaded message pump + the existing worker-thread IPC.
- **Default language = detected system language** — no hardcoded Chinese. `ui.toml` (PROGRAMDATA) stores `lang`; missing → `Lang::detect_system()`.
- **Bilingual strings everywhere:** window title, controls, list column headers, buttons, tray menu, status/error messages, advanced editor fields, and the generated `aetheris.toml` template comments — via one string table.
- **SaveConfig stays elevated-gated; service/engine untouched.** Checklist → Config mapping happens in the UI before the existing SaveConfig call.
- **"从运行中进程选择" is UI-local** (`EnumProcesses`), no IPC change.
- Dependencies locked; cargo-deny green. Every task ends green + committed.

### Task 1: i18n core — Lang, detection, ui.toml, bilingual template

**Files:**
- Create: `crates/aetheris-core/src/i18n.rs` (new module; `pub mod i18n;` in lib.rs)
- Modify: `crates/aetheris-core/src/config.rs` (`default_config_str` becomes `default_config_str(lang)`)
- Modify: `crates/aetheris-core/Cargo.toml` (add `Win32_Globalization` feature if not present)
- Test: `crates/aetheris-core/tests/i18n.rs`

**Interfaces:**
- Consumes: nothing.
- Produces:
  - `#[derive(Clone, Copy, PartialEq, Eq, Debug, Serialize, Deserialize)] pub enum Lang { Zh, En }` in `i18n.rs` (serde: `"zh"` / `"en"` via `#[serde(rename_all = "lowercase")]`).
  - `pub fn detect_system() -> Lang` — `GetUserDefaultUILanguage()` returns a LANGID; `PRIMARYLANGID == LANG_CHINESE` (0x04) → `Zh`, else `En`. (Verify the `Win32::Globalization` constant names; fall back to checking the primary-language byte: `(langid & 0xFF) == 0x04`.)
  - `pub fn ui_settings_path() -> PathBuf` = `%PROGRAMDATA%\aetheris\ui.toml`.
  - `pub struct UiSettings { pub lang: Lang }` (serde Default; `Default` impl uses `detect_system()`).
  - `pub fn load_ui_settings() -> UiSettings` (read ui.toml; missing/corrupt → default = detect_system) and `pub fn save_ui_settings(s: &UiSettings) -> Result<(), String>` (create dir, write).
  - `config::default_config_str(lang: Lang) -> String` — the template with comments in the given language (two full comment sets: zh + en; the en set is the current English comments; write a zh set).

### Task 3: Main-view rewrite — checklists + toggles + status + start/stop

**Files:**
- Modify: `crates/aetheris-bin/src/mode_ui.rs` (the main view)
- Test: manual (layout shows; toggles persist in local Config; save path works)

**Interfaces:**
- Consumes: `tr`, `apply_language`, the existing `UiState`, `client_call`, `Request::{GetConfig, SaveConfig, GetState, StopService}`, `Config`/`GameConfig`/`BackgroundRule`.
- Produces: the main window becomes:
  - **Status area** (top): a status static (`正在优化中 / 未运行` etc. per lang) + `[启动服务]` / `[停止服务]` buttons (tray-menu actions exposed in-window).
  - **游戏 list** (`SysListView32`, single column "进程名"): rows = `cfg.game.processes`; checkbox per row (LVS_EX_CHECKBOXES). `[从运行中选]` + `[添加]` buttons append rows.
  - **后台应用 list**: rows = `cfg.background` (name shown; checkbox = enabled). Same add buttons.
  - **优化方式** group: four checkboxes — `挂起` → suspend, `降优先级` → below_normal, `限制CPU [低|中|高]` (a combo 低/中/高 → 30/50/70), `清理内存` → trim_memory. These are the DEFAULT fields applied to checked background rows on Save.
  - **`[保存]`** → build a Config from the checklists + toggles + the advanced editor's overrides, `SaveConfig`, show result. **`[高级设置 ▸]`** toggles the advanced panel (Task 4).
- Checklist→Config mapping (build on Save):
  - `cfg.game.processes` = checked game rows.
  - For each checked background row: a `BackgroundRule { name, suspend, priority: low_priority.then_some(BelowNormal), qos_cpu_quota: cpu_enabled.then(level_to_pct), trim_memory }`. Unchecked rows are dropped (or kept as disabled? **Decision:** Save rewrites the lists from the checklists — unchecked rows are removed on save; the advanced editor can keep rows the checklists don't show).
  - Overrides from the advanced editor (Task 4) take precedence for rows that have them.
- Running-process picker: a modal dialog listing running processes (`EnumProcesses` + `QueryFullProcessImageNameW` for names), checkboxes, `[确定]` appends the selected names to the focused list.
