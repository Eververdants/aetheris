# aetheris v2.2.1 极简中文 UI 设计文档

日期:2026-08-10
状态:待评审
前置:v2.2.0(单 exe)已发布。本版重做 UI:从"技术型列表编辑"变"极简中文勾选界面"。

## 1. 背景

用户反馈:v2.2.0 UI 太复杂 + 全英文看不懂。目标:一个普通用户能看懂的极简中文界面,同时保留高级编辑能力。

## 2. 范围

- 主界面极简化:双勾选列表 + 全局优化方式 + 大状态区。
- 全中文:窗口控件、托盘菜单、状态消息、`aetheris.toml` 模板注释。
- 高级折叠:保留逐行字段编辑(中文),默认收起。
- 添加辅助:"从运行中进程选择"弹窗(不用记进程名)。

## 3. 主界面布局(全中文)

```
┌────────────────────────────────────────┐
│  aetheris  —  游戏优化                   │
│  状态:● 正在优化中        [启动服务] [停止] │
│  ┌─ 游戏(启动时进入优化模式)───────────┐  │
│  │ ☑ game.exe              [从运行中选] │  │
│  │ ☐ steam_app_*.exe       [添加]      │  │
│  └──────────────────────────────────┘  │
│  ┌─ 后台应用(游戏运行时优化)──────────┐  │
│  │ ☑ chrome.exe             [从运行中选] │  │
│  │ ☑ msedge.exe             [添加]      │  │
│  └──────────────────────────────────┘  │
│  优化方式(应用到全部勾选的后台应用):        │
│  ☑ 挂起  ☑ 降优先级  ☑ 限制CPU[低|中|高]  ☑ 清理内存 │
│  [保存]  [高级设置 ▸]                  │
└────────────────────────────────────────┘
```

## 4. 数据映射

- **游戏列表** ↔ `[game] processes`。勾选 = 在该进程启动时进入 GameBoost。
- **后台列表** ↔ `[[background]]` 规则。勾选 + 全局方式 → 保存时生成规则字段:
  - ☑ 挂起 → `suspend = true`
  - ☑ 降优先级 → `priority = "below_normal"`
  - ☑ 限制CPU 低/中/高 → `qos_cpu_quota = 30 / 50 / 70`
  - ☑ 清理内存 → `trim_memory = true`
- 全局方式 = 勾选后台应用的默认字段;高级编辑可逐项覆盖。
- 保存走既有 `SaveConfig`(校验 + 原子写 + reload,提权检查)。

## 5. 高级设置(折叠)

- 默认收起;展开后为现有逐行编辑(优先级下拉、亲和性文本、QoS 值、挂起/清内存勾选),全中文。
- 保留"Reload 配置"与"保存"。
- 主界面与高级共用同一份本地 `Config`,切换视图不丢编辑。

## 6. 添加辅助:从运行中进程选择

- 点击"从运行中选中"→ 弹窗列出当前运行进程(经新 IPC `Request::ListProcesses` → 服务返回进程名列表,或 UI 本地 `EnumProcesses`)。**决策:UI 本地 `EnumProcesses` + `QueryFullProcessImageNameW`**(不改服务、不加 IPC、提权无关)。勾选进程 → 追加到对应列表。
- 输入添加:文本输入进程名(支持 `*` 通配)。

## 7. 中英文切换(i18n)

- **双语言字符串表**:`enum Lang { Zh, En }` + 每串 `fn tr(lang, key) -> &'static str`(或按 `Lang` 返回的字段结构体)。覆盖:窗口标题、全部控件标签/按钮/列表列头、托盘菜单、状态/错误消息、高级设置字段。
- **语言设置存储**:`%PROGRAMDATA%\aetheris\ui.toml`(`lang = "zh"|"en"`)。UI 启动时读;语言切换按钮立即写文件 + 重绘全部控件文本。**不经过 SaveConfig**(语言切换应即时生效,不与主配置保存耦合;无提权需求)。
- **首次运行自动检测系统语言**:`Lang::detect_system()` 经 `GetUserDefaultUILanguage`(`Win32::Globalization`):主要语言为中文(zh-CN/zh-TW/zh-Hans 等) → `Zh`;否则 `En`。ui.toml 不存在时按检测结果写入并作为默认。UI 启动即在检测语言。
- **`default_config_str(lang)`**:模板注释按语言生成 — `zh` → 中文注释,`en` → 英文注释(两套注释文案)。首次生成的配置文件注释 = 检测到的系统语言。
- **切换入口**:窗口标题栏旁"语言 / Language"按钮;托盘菜单同步切换。切换后全部控件、托盘菜单、后续消息立即变语言。
- **`default_config_str()` 模板注释**:中文(默认 zh 用户)。en 用户主要靠英文 UI;toml 注释为中文属可接受(配置为次要面)。产品名 `aetheris` 双语均保留(品牌)。
- **高级设置字段**同样双语(优先级下拉值、按钮等)。

## 7b. 默认范围(按检测到的系统语言)

- 首次运行自动检测系统语言,默认即为该语言(中文系统 → 全中文界面;英文系统 → 英文界面)。
- lang=zh 时:窗口标题、所有控件标签、按钮、托盘菜单、状态/错误消息、模板注释均为中文。
- lang=en 时:以上均为英文(含英文模板注释)。
- 产品名 `aetheris` 双语均保留(品牌)。

## 8. 全局约束

- 无 async runtime;UI 单线程消息泵 + 工作线程(沿用 v2.1-4 非阻塞 IPC)。
- 安全:SaveConfig 仍提权门;托盘/服务/overlay 生命周期不变。
- 单 exe 不变;`aetheris ui` = 新界面。
- 核心 `aetheris-core` 引擎不动(仅 IPC 无新增)。
- 每个任务绿 + 提交。

## 9. 测试策略

- 数据映射:勾选+全局方式 → 生成 Config 字段(单元测试)。
- 进程列举:UI 本地 `EnumProcesses` 冒烟(数量 > 0)。
- 界面:手工验证(中文显示、勾选→保存→服务生效、高级展开编辑、运行中进程选择、托盘中文菜单)。
- 全量 `cargo test --workspace` + cargo-deny。

## 10. 验收标准

1. `aetheris ui` 主界面全中文,无技术性字段暴露在表层。
2. 勾选游戏/后台 + 全局方式 → 保存 → 服务 reload,行为生效(get-state 验证)。
3. "从运行中进程选择"列出进程可点选。
4. 高级折叠可逐项微调,切换视图不丢编辑。
5. 托盘菜单中文。
6. 首次运行生成的 toml 注释中文。
7. 语言切换:点"语言/Language"→ 全部控件、托盘菜单立即切换中/英;重启后保持(lang 读自 ui.toml)。
8. 首次运行自动检测系统语言(GetUserDefaultUILanguage):中文系统 → 中文界面 + 中文模板注释;英文系统 → 英文。检测逻辑有单元测试。
9. 全部测试绿。

- 发布:tag v2.2.1,release 单 `aetheris.exe`。
